## 1. What is Programming?
Programming means giving instructions to a computer to perform a task.<br>
or
Programming is the process of designing and writing instructions that a computer can execute to solve a particular problem.
### For example, suppose you want a computer to calculate:
    10 + 20
You need to give the computer instructions.
### Real-life example
#### If you tell a person:
Take two numbers, add them, and tell me the answer.<br>
That is an instruction.<br>
Similarly, programming is giving instructions to a computer in a language it can process.
## 2. What is Coding?
Coding is writing those instructions using a programming language.
## 3. What is a Programming Language?
A programming language is a formal language used by programmers to write instructions that a computer can execute to perform specific tasks.
## 4. difference between program, progamming, programming language?
The actual set of instructions/code written using that language<br>
The process of creating instructions to solve a problem<br>
The language used to write those instructions




# Why Java is popular?
    Java = Platform Independence + OOP + Reliability + Security + Performance + Huge Ecosystem + Industry Adoption
Java is popular because it is platform-independent through the JVM, object-oriented, secure, reliable, scalable, and has a huge ecosystem of libraries and frameworks. It is especially widely used for large enterprise and backend applications, which has created a large developer community and long-term industry adoption.
