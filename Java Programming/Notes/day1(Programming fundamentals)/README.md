## 1. What is Programming?
Programming is the process of designing and writing instructions that a computer can execute to perform tasks or solve problems.<br>
### Programming includes:
    Problem analysis
    Planning the solution
    Coding
    Testing
    Debugging
A computer does not automatically know what we want. We must provide instructions in a language that can be translated into instructions the computer can execute.<br>
### Example: Adding Two Numbers
Suppose we want a computer to add two numbers.
### Steps:
    Take the first number.
    Take the second number.
    Add both numbers.
    Display the result.
    
    Example input: 10 and 20
    Output: 30
## 2. What is Coding?
Coding is the process of writing instructions using a programming language to tell a computer what to do.<br>
Coding is one part of programming.<br>
### Coding mainly involves:
    Writing code using a programming language.
    Following the language's syntax and rules.
    Translating a planned solution into code.
### Example
    System.out.println(10 + 20);
    Output:
    30
## 3.Is coding the same as programming?
No. Coding is the process of writing code, whereas programming is the broader process of developing a solution, including problem analysis, planning, coding, testing and debugging.
## 4. What is a Programming Language?
A programming language is a formal language used by programmers to write instructions that a computer can execute to perform specific tasks.
### popular programming languages:
     Java
     Python
     C
     JavaScript
## 5.What is Program?
A program is a set of instructions written to perform a particular task.<br>
For example, a calculator program can add, subtract, multiply and divide numbers.

who write code, test, debug and maintain systems is called programmer.
## 7.What is problem-solving?
Problem-solving means understanding a problem and finding a logical way to solve it.
### A useful problem-solving process is:
    1. Understand the problem
    2. Identify inputs and outputs
    3. Design the logic
    4. Write the code
    5. Test the result
    6. Debug and improve
## 8. What is an algorithm?
An algorithm is a finite sequence of clear steps used to solve a problem.
### Example: Algorithm to add two numbers.
    Start.
    Read two numbers, A and B.
    Calculate SUM = A + B.
    Display SUM.
    Stop.
An algorithm describes the logic, not necessarily the programming language.

## 10. What is pseudocode?
Pseudocode is a simple, informal way to describe an algorithm using human-readable statements that resemble programming logic.<br>
It does not need to follow the exact syntax of Java, C or Python.
### Example: Find the largest of two numbers.
    START
    INPUT A, B
    IF A > B
        PRINT A
    ELSE IF B > A
        PRINT B
    ELSE
        PRINT "Both are equal"
    END IF
    STOP

## 11. Introduction to Java
Java is a high-level, general-purpose programming language originally developed at Sun Microsystems. It was led by James Gosling and released publicly in 1995.<br>
Java is widely used for enterprise software, backend services, financial systems, large applications and many other areas.
## 12. Why learn Java?
Object-oriented programming support.<br>
Strong type checking.<br>
Automatic memory management through garbage collection.<br>
A large standard library and ecosystem.<br>
Platform independence through the JVM.<br>
Widely used in enterprise backend development.
## 13. Why Java is popular?
    Java = Platform Independence + OOP + Reliability + Security + Performance + Huge Ecosystem + Industry Adoption
Java is popular because it is platform-independent through the JVM, object-oriented, secure, reliable, scalable, and has a huge ecosystem of libraries and frameworks. It is especially widely used for large enterprise and backend applications, which has created a large developer community and long-term industry adoption.
## 14. What does “Write Once, Run Anywhere” mean?
Java source code is compiled into bytecode. A compatible Java Virtual Machine (JVM) can execute that bytecode on different operating systems.<br>
