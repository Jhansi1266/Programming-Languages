# Variables
A variable in C is a named memory location used to store a value of a particular data type, and its value can be changed during program execution.<br>
If you want to drink water, you first put water inside a glass and then drink it.<br>
Similarly, you can think of a variable as a glass and the value as the water inside the glass.<br>
Glass  → Variable<br>
Water  → Value<br>
# Declaration
Variable declaration means telling the compiler that a variable exists and specifying its data type.
## Properties:
    1. Size of the variable

# Initialization of a Variable in C
Initialization means giving a variable its first value when the variable is created.
## Syntax
    data_type variable_name = value;
## Example
     int var=3;
